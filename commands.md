# Common Shell Commands

## File and Dir Management

``` bash
ls 	# list
cd 	# change directory
pwd 	# print working directory
mv	# move or rename
rm 	# remove (delete)
mkdir	# make a new directory
touch	# create or update a file
find	# find a file based on a pattern
tar	# tape archive

## Text processing and viewing
cat	# concatenate
less	# show a file on the screen
grep	# Global Regular Expression Print
head	# show the beginning of a file
tail	# show the end of a file
nano 	# simple text editor
vi	# hard to use text editor
echo	# print a value to the screen

## System and Process 
ps	# show a process 
top	# what are the top running processes right now?
kill	# kill/destroy a running process
df	# disk free (how large is a file on the disk?)
du 	# disk usage (how large is on the disk?)
history # how has this file changed over time?

## permissions and administration
sudo 	# allow the current user to assume adminsistrative powers
chmod	# change the access mode of this file
chown	# change file ownership

## networking and internet
ping	# is the remote host responding to us?
wget	# grab a file from the web
curl 	# a better version of wget
ssh	# secure shell - make a connection to a remote 
man	# read the manual page for a command

```
